# Calculadora de IMC (JavaFX)

Este projeto é uma aplicação simples desenvolvida em **JavaFX** para
calcular o **IMC (Índice de Massa Corporal)**.

## Funcionalidades

-   Entrada de peso (kg)
-   Entrada de altura (m)
-   Cálculo automático do IMC
-   Mensagens de erro para entradas inválidas
-   Interface gráfica simples usando VBox

## Como executar

### Compilação via terminal:

``` bash
javac --module-path /caminho/javafx/lib --add-modules javafx.controls CalculadoraIMC.java
java --module-path /caminho/javafx/lib --add-modules javafx.controls CalculadoraIMC
```

## Pré-requisitos

-   Java JDK 8+
-   JavaFX SDK compatível
